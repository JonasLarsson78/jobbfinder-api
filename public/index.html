Jobbfinder API

Det här är en enkel beskrivning av hur du använder Jobbfinder API:t som körs på http://localhost:3000.

Bas-URL

Alla endpoints utgår från:
http://localhost:3000/jobs

Endpoints

GET /jobs

Hämtar en lista med jobb baserat på olika sökparametrar.

Query-parametrar (exempel)

  • q – fritextsökning (titel, beskrivning, etc.)
  • municipality – kommun (t.ex. "Stockholm")
  • limit – antal jobb att hämta (standard kan variera)
  • offset – för paginering (hoppa över N jobb)

Exempelanrop med curl

curl "http://localhost:3000/jobs?q=utvecklare&municipality=Stockholm&limit=20"

Exempelanrop i JavaScript (fetch)

fetch("http://localhost:3000/jobs?q=utvecklare&municipality=Stockholm&limit=20")
	.then(res => res.json())
	.then(data => {
		console.log("Antal jobb:", data.length);
		console.log(data);
	})
	.catch(console.error);

HTTP-svar

API:t returnerar JSON. Strukturen beror på om du frågar efter en eller flera städer.

1 stad (t.ex. ?city=Stockholm)

Exempelsvar:

{
	"city": "Stockholm",
	"municipalityCode": "0180",
	"query": "utvecklare",      // din q-parameter (kan vara tom sträng)
	"result": {
		"total": 42,               // totalt antal matcher (AF + ev. LinkedIn)
		"afMatches": [
			{
				"headline": "JavaScript-utvecklare",
				"employer": "Företag AB",
				"webpage_url": "https://...",      // länk till annons/ansökan
				"application_deadline": "2026-03-31", // YYYY-MM-DD eller null
				"number_of_vacancies": 1,           // antal tjänster eller null
				"conditions": "Start: Omgående; ...", // kort sammanfattning om villkor om möjligt
				"salary_description": "Fast lön"   // om tillgängligt
			}
			// ... fler jobb
		],
		"linkedinMatches": [
			{
				"title": "Frontend Developer",
				"company": "LinkedIn AB",
				"location": "Stockholm, Stockholm, Sverige",
				"datetime": "2026-03-01",               // publiceringsdatum från <time datetime="...">
				"url": "https://www.linkedin.com/jobs/view/..." // direktlänk till jobbannons på LinkedIn
			}
			// ... fler LinkedIn-jobb
		]
	}
}

Flera städer (t.ex. ?city=Stockholm&city=Göteborg)

Exempelsvar:

{
	"queries": [
		{
			"city": "Stockholm",
			"municipalityCode": "0180",
			"result": { "total": 42, "afMatches": [ /* ... */ ], "linkedinMatches": [ /* ... */ ] }
		},
		{
			"city": "Göteborg",
			"municipalityCode": "1480",
			"result": { "total": 10, "afMatches": [ /* ... */ ], "linkedinMatches": [ /* ... */ ] }
		}
	],
	"notFound": [
		// lista med städer som inte kunde matchas mot en kommunkod
		// t.ex. ["OkändStad"]
	]
}

Om JobTech JobSearch-API:t eller LinkedIn-scrapingen ger fel för en viss stad markeras detta i respektive objekt under queries med ett error-fält istället för result.

Felhantering

Vid fel (t.ex. externa API:n nere eller ogiltiga parametrar) kan API:t svara med relevant HTTP-statuskod (t.ex. 500 eller 400). Kolla svarskod och innehåll i svaret för mer info.

Tips: öppna utvecklingskonsolen i webbläsaren (Network-fliken) när du testar anrop för att se exakt vilka requests som görs och vilka svar som kommer tillbaka.
